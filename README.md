## Notificação por e-mail
O site envia a confirmação para `kakagomes620@gmail.com` usando FormSubmit.
Na primeira vez, o FormSubmit envia uma mensagem de ativação/confirmação para esse e-mail. Depois de confirmar, os próximos convites são encaminhados automaticamente.

Se a confirmação não aparecer, verifique Spam/Lixo eletrônico e faça um novo teste no site.
